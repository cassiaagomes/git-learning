# O que é Git?

## Introdução

O Git é um sistema de controle de versão distribuído (Distribited Version Control System - DVCS) criado por Linus Torvalds em 2005.

Seu principal objetivo é registrar e gerenciar o histórico de alterações em arquivos, permitindo que desenvolvedores trabalhem de forma organizada, segura e colaborativa em um mesmo projeto. 

Com o Git, é possível acompanhar todas as modificações realizadas ao longo do desenvolvimento, recuperar versões anteriores, criar funcionalidades em paralelo e integrar alterações de diferentes membros da equipe. 

---

## Como o Git funciona? 

O Git registra o estado dos arquivos por meio de **commits**, que funcionam como pontos de salvamento do projeto. 

Cada commit representa uma versão específica do código, contendo informações como:

- Alterações realizadas;
- Autor da modificação;
- Data e Horário;
- Mensagem descritiva da alteração; 

Esses registros formam um histórico completo do projeto, permitindo navegar entre versões sempre que necessário. 

---

## Principais vantagens do Git
- Controle completo do histórico de alterações.
- Facilidade para trabalhar em equipe. 
- Possibilidade de criar branches para desenvolver funcionalidades isoladamente. 
- Recuperação de versões anteriores do projeto.
- Resolução de conflitos durante a integração de alterações.
- Integração com plataformas como GitHub, GitLab e Bitbucket. 

---
## Git x Github
Embora sejam frequentemente utilizadas em conjunto, Git e Github possuem funções diferentes.

Git: 

- Sistema de controle de versão. 
- Funciona localmente no computador.
- Gerencia o histórico do projeto

Github: 

- Plataforma de hospedagem de repositórios git.
- Funciona na nuvem.
- Facilita colaboração, Pull Requests e revisão de código.

---

## Quando utilizar o Git?

O git pode ser utilizado em qualquer projeto que possua arquivos, como: 

- Desenvolvimento de software;
- Ciência e Engenharia de Dados;
- Documentação;
- Sites;
- Trabalhos acadêmicos;
- Projetos pessoais;

---

## Resumo

O Git é uma ferramenta essencial para o desenvolvimento moderno, pois permite controlar versões, organizar alterações, colaborar com equipes e manter um histórico competo de um projeto de forma segura e eficiente.
